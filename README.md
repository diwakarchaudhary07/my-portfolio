# Diwakar Kumar Chaudhary — Portfolio

Responsive personal portfolio built with plain HTML, CSS and JavaScript. No npm packages or build step are required.

## Run locally
1. Download and extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
4. Before publishing, update the LinkedIn placeholder URLs and set `PORTFOLIO_EMAIL` in `script.js`.

## Customize
- `index.html`: your introduction, education, projects, links and certificates.
- `style.css`: colors, spacing, responsive layout and visual design.
- `script.js`: mobile navigation, theme toggle, scroll progress, active section and contact form behavior.

## Deploy on GitHub Pages
1. Create or open repository `my-portfolio` on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait for GitHub Pages to publish the website. Your current portfolio URL may be `https://diwakarchaudhary07.github.io/my-portfolio/`.

## Notes
- The portfolio avoids invented statistics and proficiency scores.
- Project descriptions reflect details shared by the owner; review current repositories before publishing.
- The contact form opens the visitor's default email application. It does not send mail from a server.
- Update `https://www.linkedin.com/` placeholder links with the exact LinkedIn profile URL.
